This branch contains only public synthetic exact-rational tests. No private project files or original CP archives are uploaded.

- CP01: sharp Fréchet marginal bounds and constructive witnesses.
- CP02: strict exact-rational input validation, 2x2 certificates and mutation tests (NOT complete original generic transport checks).

The workflow produces four separate jobs and uploaded receipts with source hashes and run logs. It is *not* an independent external review, Lean kernel proof or full archived-source replay.
