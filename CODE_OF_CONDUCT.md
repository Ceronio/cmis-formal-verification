# Code of Conduct

CMIS Formal Verification is an evidence-led public research project. Participation should improve accuracy, reproducibility and understanding.

## Expected behaviour

- Be precise, respectful and constructive.
- Criticise claims, methods and evidence rather than people.
- Distinguish facts, interpretations and uncertainty.
- Preserve source attribution and theorem scope.
- Correct errors openly and retain material audit history.
- Welcome good-faith questions from people with different levels of formal-methods experience.

## Unacceptable behaviour

- Personal attacks, harassment or discriminatory conduct.
- Fabricated results, altered receipts or knowingly misleading scope claims.
- Publishing private data, credentials or confidential project material.
- Spam, manufactured engagement or attempts to game stars and recognition.
- Presenting external mathematics as CMIS-authored without evidence.

## Enforcement

Public issues or contributions that breach these rules may be edited, closed, locked or removed. Serious security or privacy concerns should be reported privately through GitHub's Security reporting function rather than posted publicly.

The aim is firm technical scrutiny in a professional environment where corrections strengthen the project.
